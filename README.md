# Бот для расчёта сайдинга по фото

Telegram-бот считает виниловый сайдинг U-Plast и комплектующие по фотографиям дома и выдаёт смету с ценами.

## Как работает

1. Пользователь присылает 1–5 фото дома, лучше с разных сторон.
2. Claude оценивает по фото длину, ширину и высоту стен, тип кровли, высоту фронтонов, окна, двери и углы. Масштаб берётся по типовым размерам двери и окон.
3. Бот показывает карточку параметров. Значения со знаком «≈» — это оценка по фото.
4. Пользователь уточняет хотя бы один размер (например, длину дома). Остальные размеры бот пересчитывает пропорционально фото. Любой параметр можно поправить кнопками.
5. «Рассчитать» — бот выдаёт количество материалов и сумму по прайсу.

Без фото: `/manual` открывает карточку с шаблонными размерами.

## Что считается

| Позиция | Как считается |
|---|---|
| Панели | (стены + фронтоны − окна и двери) × (1 + запас на подрезку) / полезная площадь панели |
| Стартовая планка | периметр дома минус ширина дверей |
| Наружный / внутренний угол | число углов × планок на высоту стены |
| Околооконная планка | периметры окон + дверей (без порога) |
| Финишная планка | под карнизом + под подоконниками |
| J-профиль | по скатам фронтонов |
| Саморезы | норма на м² + на каждую доборную планку, в упаковках |

Запас на подрезку (10%), запас на профили (5%), размеры и цены задаются в [`catalog.json`](catalog.json).

**Перед запуском проверьте `catalog.json`:** длины элементов и полезную ширину панели по паспорту U-Plast, а цены замените на свои. Сейчас там примерные значения.

## Запуск

Нужен Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и заполните токены
python -m siding_bot
```

В `.env`:
- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather);
- `ANTHROPIC_API_KEY` — ключ Claude API с [console.anthropic.com](https://console.anthropic.com);
- `ALLOWED_USERS` — необязательно: Telegram ID через запятую, кому доступен бот. Каждый анализ фото стоит денег, поэтому лучше ограничить доступ. Свой ID бот покажет, если написать ему, когда вы не в списке.

## Ограничения

- Дом считается прямоугольным в плане. Эркеры и пристройки добавляйте через углы и размеры вручную.
- Точность зависит от фото и уточнённых размеров. Без уточнения погрешность может быть 20–30%.
- Софиты, водосток, обрешётка и утеплитель пока не считаются.
